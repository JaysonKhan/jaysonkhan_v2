02 — Philosophy

Manifesto.

03 PRINCIPLES · ON BUILDING

01

Code is a side effect of thinking clearly.

A clean codebase is the residue of a clear understanding of the problem. I don't ship spaghetti and call it pragmatic.

02

Production is the only opinion that matters.

Demos are theatre. I measure my work by App Store reviews, crash-free sessions, and revenue clients can count.

03

Boring infrastructure is high craft.

CI that never fails. Migrations that never lose data. Observability you actually use. The unglamorous parts are where senior engineers earn their fee.

05 — How I work

Five steps,
no surprises.

01

Diagnose

A 60-minute call. We map the actual problem behind the brief — not the symptom.

02

Architect

A 1-week sprint to lay out the data model, state shape, integration surfaces. No code yet.

03

Build in slices

End-to-end working features each week. You can run it on your phone from day 7.

04

Harden + ship

Beta with real users, telemetry wired, rollout plan agreed. Then App Store + Play Store on the same day.

05

Operate

Optional retainer. Crash triage, telemetry reviews — the boring middle that keeps things alive.
